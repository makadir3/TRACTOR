## C. Generate datasets (repeat each `T`)

From `python/`:

```bash
cd python
for T in 4 8 16 32 64; do
  python ORAN_dataset.py \
    --trials Trial1 Trial2 Trial3 Trial4 Trial5 Trial6 \
    --mode emuc --slicelen "$T" --data_type singleUE_raw \
    --drop_colnames Timestamp num_ues IMSI RNTI slicing_enabled slice_id slice_prb scheduling_policy \
    --ds_path ../logs --cp_path ./repro_logs \
    --exp_name "tractor_cnn_T${T}" --filemarker "repro_T${T}"
done
```

Inspect each generated normalizer and assert exactly 17 ordered feature names. The exact output filenames are generated by `ORAN_dataset.py`; record them rather than guessing.

## D. Train the paper CNN

```bash
cd python
T=64
python torch_train_ORAN.py \
  --ds_file <generated-dataset-for-T64.pkl> \
  --isNorm --ds_path ../logs \
  --cp_path ./repro_logs --exp_name tractor_cnn_T64 \
  --norm_param_path <generated-normalizer-for-T64.pkl> \
  --patience 30 --lrmax 1e-3 --lrmin 1e-5 --lrpatience 10 \
  2>&1 | tee ../work_handoff/artifacts/train_T64.log
```

Omit `--transformer`: that selects the CNN. Repeat for all five `T` values. The code has no seed CLI; any seed patch must be explicitly documented as a modification.
